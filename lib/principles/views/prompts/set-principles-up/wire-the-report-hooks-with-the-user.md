Show the user the entries for the host this session runs in, and the file they go in, and write them, merged into
any hooks the file already has, only once the user agrees. Leave them out of a committed settings file unless
every teammate has principles installed, since each hook would fail for one who has not. Codex runs them only once
the user trusts them in /hooks.

They run the session-start and after-commit reports that the principles plugin's hooks run. To remove them, as when
the principles plugin is enabled and the reports would come twice, delete the entries whose command starts
`principles report-`.
