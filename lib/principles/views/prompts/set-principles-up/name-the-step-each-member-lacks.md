These places are mapped as keeping the principles held, each with the role its member gives it:

%{members}

A place keeps them held only through what triggers it: a hook, a timer or a reader. With the user, name which of
the keeping steps each one lacks: running `principles list-member-problems --short` at session start, after a
compaction and after each commit that edits a mapped file, and acting on what it reports. The members listed in
members_in_entry_files are the ones in an entry file. This tool writes none of the project's guidance.

Where a step is missing, the passage is one way to add it, at %{estimated_tokens} estimated tokens in every session
that loads the entry file it goes in.

Place the passage exactly as printed, adding nothing to it and changing none of its words.

Once the passage is placed, map it: %{command}

To map another place that runs a missing step, giving as STEP the step it runs and as TRIGGER what starts it: %{any_place}
