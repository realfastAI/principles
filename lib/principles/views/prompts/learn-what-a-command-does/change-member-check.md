Names COMMAND as the check that enforces MEMBER of principle ID, replacing any check it had. MEMBER is
the id `show-principle` lists.

Each audit asks you to run COMMAND in the project and report its exit status, or why you could not run
it. The first audit after the check changes marks it changed, with the commit that changed it, and asks
for it to be reviewed before it runs. This tool stores COMMAND exactly as given and never runs it, so it cannot confirm that a reported run
happened. When COMMAND holds a character that prints escaped or not at all, such as a zero-width space or a
right-to-left override, the result's `check_hidden_characters` names each with its code point, its name where
known and its position; make sure each is meant. Stop naming a check with `remove-member-check`.

Run during a full audit, between an accepted assessment and its correction, to fix a finding in the map: list MEMBER
in the `changed_map_entries` of the fixed disposition it fixes, and submit the correction. This tool prints both
that step and starting the audit, since it cannot tell in git whether a correction is open.

An id no member has is refused with `unknown_member`. When it differs from one mapped id only in case, spacing,
dashes or quotes, the refusal names that id under `did_you_mean` and starts its repair with this command run on it
instead. This tool never acts on the near miss: check that it is the member you meant before you run it.
