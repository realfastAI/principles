An edit made by habit can make an always-loaded file heavier, put a task's rule where every session reads it, or
leave a "never" with no reason. Run this command before you judge or edit a member when you want more than the
one-paragraph check for its carrier kind: it prints that kind's page of practices, a few kilobytes. It writes
nothing.

KIND is one of `instructions` (`CLAUDE.md`, `AGENTS.md` and their kin), `rule` (a `.claude/rules` file), `skill`,
`subagent`, `hook_configuration` (a settings or hooks file), `hook_script` (a file a hook command runs) and `none`,
the page for any other text an agent reads, such as a docs page or text a program prints into context.

It prints `carrier`, `practices`, the page as Markdown, and an empty `wrote`.
Each point on a page says which host it holds for when it holds for only one.

It refuses with `unknown_carrier_kind` a kind it has no page for, and its repair names each kind it has.
